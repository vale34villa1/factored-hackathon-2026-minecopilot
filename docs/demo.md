# Demo notes

This repository contains a functional MVP for a mine operations copilot. It is designed to demonstrate a hackathon flow:

1. Data ingestion from mining files.
2. Operational summary and KPI extraction.
3. Risk and Lean waste evaluation.
4. Recommendation engine.
5. Conversational interaction through Streamlit.

Run locally with:

```bash
pip install -r requirements.txt
streamlit run app.py
```

The app is structured for easy extension to a more advanced LLM/RAG version.
